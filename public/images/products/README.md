# Product photos

I couldn't pull the product photos you pasted into the chat down into this
sandbox as real files, so the store currently shows a styled placeholder
(colored card + emoji icon) for every product instead of a photo.

To use your real photos, just drop them here with these exact filenames —
the site already links to these paths and will pick them up automatically,
no code changes needed:

- `hayacare-vaginal-cream.jpg`
- `vagina-tightening-cream.jpg`
- `likoria-care.jpg`
- `manmax.jpg`
- `joint-care.jpg`

Recommended: square images, at least 800x800px, JPG or PNG, ideally under 300KB each.
